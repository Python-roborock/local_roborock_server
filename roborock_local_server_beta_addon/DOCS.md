# Roborock Local Server Beta

This entry targets the opt-in `1.2.2-rc1` image. Install **Roborock Local Server**
for stable releases. The prerelease image must be published before this version
is made available to users; changing add-on options alone cannot update an older
image. Follow the [stable setup documentation](../roborock_local_server_addon/DOCS.md)
for TURN modes and optional UDP mappings.

Beta and stable have separate settings and data. Follow
[switching from Beta to stable](https://python-roborock.github.io/local_roborock_server/updating/#switching-from-beta-to-stable)
if you used Beta during RC testing.
